# GAX100 – äldre källinventering (arkiv)

**Detta är inte längre det aktiva GAX100-projektet.** Den publicerade produkten, testerna och publiceringsflödet finns i [TheGAX100-splits](https://github.com/Stayinhealthyrunning/TheGAX100-splits). Loppkortet finns på [Loppanalys.se](https://www.loppanalys.se/).

Detta repo behåller endast den ursprungliga källinventeringen (`SOURCE_REGISTER.md`, `DATA_COVERAGE.md`) och ett integritetsskydd för ändringar. Inventeringen beskriver läget i oktober 2026 och är **inte** en aktuell statusrapport.

**Integritetsvarning:** En radering av filer i den aktuella grenen rensar inte historiska commits eller andra grenar. Repo och historik måste granskas separat för tidigare personuppgifter innan det kan raderas eller betraktas som sanerat. Kopiera aldrig äldre rådata till det aktiva repot.

Inga nya funktioner, resultatimporter eller GitHub Pages-publiceringar ska ske här. All ny utveckling sker i TheGAX100-splits.
