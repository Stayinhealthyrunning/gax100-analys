## Semantics and reproducibility

- `FINISHED` requires an explicit or source-supported valid finish time.
- `DNF`, `DNS` and `DSQ` are imported only from source-supported status text. Absence of a time never infers DNS or DNF.
- `UNKNOWN` remains explicit when an older source has a result row but no reliable finish/status field.
- Observations are kept separate from finish results. Segment times are derived only from adjacent, positive-distance, chronological observations; invalid or backward observations break the sequence.
- Every result and observation retains source provenance and the original raw JSON in the ignored SQLite build, while the public web export omits raw JSON and source archive paths.
